# dinlom

Android-приложение «Астрономический гид» для дипломного проекта.

## Регистрация и база данных

В приложении есть экран регистрации пользователя. Сейчас он сохраняет данные локально через Room, чтобы форму можно было показать без отдельного сервера.

Если у вас уже есть готовая PostgreSQL-база, не подключайте Android напрямую к PostgreSQL. Правильная схема:

```text
Android-приложение → backend API → PostgreSQL
```

Подробная инструкция по подключению готовой PostgreSQL-базы находится в [`docs/postgresql-integration.md`](docs/postgresql-integration.md).
